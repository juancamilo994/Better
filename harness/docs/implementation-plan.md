Weights total 100; one points check per criterion. Supporting subchecks add no deductions. Separate points/coverage/subtotal/raw/deal-breakers/capped total. Unknown stays unknown with no normalization. Desktop/mobile stay separate. Proposed cap of 49 needs applicable verified failure. Runtime/contrast/320px verifiers absent, therefore unknown. Zero/half/full are proposed choices; exact half, intermediate points, usability/AI-flag deductions require calibration. Source bands configured; pairwise disabled metadata.

Large ten-criterion fingerprint leads. Unknown points hollow/unconnected. Mobile numbered markers plus readable legend. Brief captures URL/audience/feeling/core job. Saved projects/runs/viewports use existing objects. Fix selection saves one prompt; evidence/policy disclosed on demand. Capturing/failed/setup-needed/unknown/sample states explicit. 44 px controls, focus, 360/400 px layouts. No external assets/animation.

Canonical issue catalog goes through the live judge request/response boundary: foreign-home findings abstain, missing ownership fails validation, repeated identities cannot contribute twice. Claims presentation is not company truthfulness.
